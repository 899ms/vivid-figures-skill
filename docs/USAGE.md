# 怎么用 Vivid Figures

[返回首页](../README.md) · [安装指南](INSTALL.md)

## 给 AI 什么材料

把 CSV、Excel、JSON 或已有实验结果放进当前项目，告诉 AI 文件位置和你想比较什么。只提供结论文字，通常不足以画出可信的数据图。

最简单的请求是：

```text
用 vivid-figures-skill 读取 experiment.csv。
我想知道各个方法的结果差异和稳定性，帮我选图并绘制。
用鲜艳版、珊瑚青绿配色，输出 PNG、PDF 和绘图源码。
```

如果数据里没有重复试验，AI 就没有依据画“试验波动”或置信区间。你可以补充样本数据，也可以让它只画已有结果。

## 指定风格和颜色

**鲜艳版**偏向明亮、有层次的表达**；稳重版**偏向规整、直接的表达。两种模式都能选择全部配色：

| 配色名称 | 大致观感 |
|---|---|
| 珊瑚青绿 | 青绿与珊瑚对比，明亮均衡；鲜艳版原配色 |
| 海洋暖橙 | 蓝色与暖橙搭配，清爽鲜明 |
| 鸢尾杏桃 | 紫色与杏桃搭配，柔和细腻 |
| 森林日光 | 绿色、青色与暖黄搭配，自然明亮 |
| 浆果冰蓝 | 莓红、冰蓝与紫色搭配，活泼通透 |
| 科研原配色 | 原有 `colorblind` 色板；稳重版原配色 |

直接说“稳重版，海洋暖橙配色”即可。没有选定时 AI 会先问；已有明确选择时会沿用。自定义颜色可以提供一组十六进制色值。

选色只改变颜色搭配，不会把稳重版变成鲜艳版，也不要求把连续色条统一换成某个主题色。完整配置说明在 [配色选择](../color-selection.md)，一般使用时不需要手动编辑标记。

## 让 AI 自己选图，或指定模板

你可以说清楚要表达的内容，让 AI 判断：

```text
比较这些组的分布：既要看中心位置，也要看离散程度。
用鲜艳版、森林日光配色，图型你来选。
```

也可以直接点名：

```text
把 samples.csv 里的七组数据画成山脊图。
用鲜艳版、浆果冰蓝配色，保留渐变填充和中位数标记。
```

Skill 会要求 AI 查找相应配方，从完整模板代码出发适配数据。模板里依赖特定数据的部分仍需要数据支持，不能为了凑出模板外观而造数。

## 修改已有图

最好同时保留图片、数据和绘图源码：

```text
修改 figures/ 里的这张图，把图例移到上方，解决右侧标签遮挡。
沿用当前风格与配色，尽量保留模板结构、渐变和标记。
```

只给截图可以讨论视觉问题；需要准确修改数值、坐标或统计表达时，仍应提供原数据或代码。

默认过程是出图后查看实际图片，汇总问题再修复。每张图最多三轮修复，通过即停止；仍有问题时说明剩余问题。你也可以明确要求“只生成首轮，先让我看效果”。

## 输出文件在哪里

通常在当前任务目录的 `figures/` 中：

- **PNG**：直接查看、插入幻灯片或文档。
- **PDF**：用于论文排版；普通线条和文字可保留矢量，部分渐变、密集点或图像层可能是栅格内容。
- **Python 源码**：保存数据读取、计算和绘制步骤，便于复现与继续修改。
- **技术图源文件**：按图型可能是 `.drawio` 或 `.tex`。

具体输出取决于你要求的格式和图型。HTML、Mermaid、AI 场景插图需要对应工具，见 [安装指南](INSTALL.md)。

## 仓库里的文件分别做什么

使用者主要看首页和本目录下的安装、使用说明。下面这些文件是给 AI 或工具读取的，不需要你逐个配置：

| 文件或目录 | 作用 |
|---|---|
| `SKILL.md` | AI 进入这个 Skill 时读取的总入口 |
| `color-selection.md` | 配色选项，以及什么时候询问用户 |
| `anthropic-host-adapter.md` | 告诉 AI 如何在当前工具里执行原绘图流程 |
| `original/` | 保留的原绘图指导、108 个配方和辅助脚本 |
| `requirements.txt` | Python 依赖清单 |
| `scripts/` | 完整图集的规划校验入口 |
| `examples/palette-showcase/` | README 示例的数据和绘图脚本 |
| `CHANGELOG.md` | 每次更新做了什么 |

任务目录中可能出现 `.codex-plot-runtime.json`。这只是工具保存可执行文件路径的兼容文件名，使用这个仓库不要求安装 Codex 或 HaJiMi。
