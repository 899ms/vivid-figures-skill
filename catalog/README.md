# 统一模板库

141 张说明卡：108 个原配方、32 个新增截图恢复模板及 1 个完整组合模板。卡片依据已生成的主要预览和绘图代码编写，已接入 skill 的检索流程，见 [数据与模板选择](../figure-selection.md)。

- `index.html`：全部模板统一展示，按用途、结构和数据要求搜索，按标签筛选；图片可点击放大。
- `cards/`：一模板一份 Markdown。
- `cards.json`：完整字段，含实际图型、用途、数据要求、结构、视觉特点、注意点、别名、相近候选及代码证据。
- `selection-index.jsonl`：一行一个简短检索条目；候选选出后再读完整卡片和预览，不需要每次加载全部源码。
- `previews/`：从本次图库逐字复制的 PNG；`thumbnails/` 仅用于网页显示。
- `sources/`：原始代码与原章节快照；六个配方另有兼容执行副本和差异记录。快照仅解释预览；绘图仍加载当前 original/ 中的完整配方。

ID 是稳定引用，图库编号只是显示顺序。`display_name` 描述实际图型；`legacy_title` 保存原名称，不能优先于实图。`tags` 为可重叠的用途与结构标签；所有模板统一检索。卡片正面显示编号、图名和标签，调用 ID 收在源码详情中；底层 ID 和文件路径保持兼容。

配色不作为固定选择条件。卡片描述填充、轮廓与层次；原代码中的独立连续色阶记录于 `literal_colormaps`，该字段只列显式常量，不代表全部配色行为。

每个原配方覆盖首个主要 Python 代码块，桑基块本身有三个输出。聚类热力图另有一个完整变体，源码随原章节保存，但尚无独立预览和说明卡。新增 SEM 组合只收录组合成品，单图不是额外模板。

已查看对应主要预览并核对绘图和数据代码，未进行逐个统计方法的全面正确性审计。实际发现的示例限制已写入卡片；模拟的区间、p 值、模型结果等不能直接作为真实数据结论。没有给模板设置美观分数或强制选择顺序。

相近候选链接用于比较，非要求组合绘制。所有卡片资源使用包内相对路径，可整体移动此目录。

每张卡片现有“源码保真要点”：具体视觉结构、保留重点、允许适配范围和可点击的源码行号。141 个主要示例共 146 条，覆盖范围与现有预览一致；不是全部变体或统计方法的正确性审计。绘制前使用方式及可选差异工具见 [源码底稿与保真要点](../template-fidelity.md)。精简目录保持简短，细节只在选中卡片后加载。

## 新增截图恢复模板

新增32个模板按提供的效果图顺序接在原库后（110–141），仍统一搜索和按标签筛选。每个条目包含完整恢复代码、PNG预览、说明卡、源码定位、来源状态和修改记录。

120张原始截图的对应关系和哈希见 [来源清单](screenshot-source-manifest.json)。其中26项可从代码截图恢复演示；其余3项缺原CSV、1项缺后续代码页、2项仅有效果图，这6项已补可运行演示并明确标注。恢复版不冒充作者原始文件；新增依赖按所选模板加载，见 [依赖清单](screenshot-requirements.txt)。
